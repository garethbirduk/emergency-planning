# OAuth installed-app flow, precisely so there is nothing extra to rot.
#
# Offline / vendored install (AC-D5): the wheels for everything below are
# committed under tools/vendor/ (pure-Python, platform-independent):
#   pip install --no-index --find-links tools\vendor -r tools\requirements.txt
# To refresh after changing a pin:
#   pip download <package>==<version> -d tools/vendor --no-deps
