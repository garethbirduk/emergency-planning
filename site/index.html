Emergency planning

A crisis plan before the crisis — so 3am panic becomes a lookup.

One spreadsheet holds where everything is: accounts, property, pensions, wishes, key documents, who does what. When someone dies, one command turns it into a dated checklist of what to do and in what order, plus a calendar with the same tasks — assigned to the people named in the plan.

Try the live demo View on GitHub

The demo runs entirely in your browser. The actual Python engine runs via WebAssembly; nothing you type is saved or sent anywhere, and it all vanishes when the tab closes. It's preloaded with a fictional family so you can see the output in seconds.
For a real plan, run it locally — your data never belongs in a browser tab or a repo: 
git clone https://github.com/garethbirduk/emergency-planning
cd emergency-planning
pip install --no-index --find-links tools/vendor -r tools/requirements.txt
python tools/wizard.py
The wizard opens a form in your browser served from your own machine, writes a workbook to your documents folder, and shows the command that generates the plan. An optional Google Calendar push can put the dated tasks on a shared family calendar.
Design principles: local-first (offline by default), one engine driven entirely by the workbook, durable (pinned vendored dependencies, plain-text outputs), and private by construction — the tool refuses to read real data from inside its own repo, and the repo holds only fictional sample people.
